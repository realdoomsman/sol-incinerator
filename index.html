💧 Fund gas

Send SOL from the main wallet to every selected wallet so they can pay fees.

🔎 Scan tokens

List all SPL token accounts (balances + empty) for selected wallets.

💱 Sell tokens

Swap all non-zero token balances to SOL via Jupiter. Unsellable tokens are skipped.

🗑️ Close accounts

Close empty token accounts and reclaim their rent SOL (~0.002 each).

🔥 Burn tokens

Destructive. Permanently destroys token balances so their accounts can be closed. Use only for junk/unsellable tokens.

🧹 Sweep SOL

Send all SOL (minus fee buffer) from selected wallets to the main wallet.
